# クロスワード工房 語彙選定ポリシー (v1.0)
更新: 2026-10-17 / APP-002 / 担当: 語彙・カギ専用セッション

## 目的
現代日本語で自然な語を厳選し、独自制作した短く具体的なカギを添える。最終目標は約2,000語。ただし件数を満たすために不自然な語を増やさない。

## 採用ルール
- 盤面で有効な2〜15マス。初期300語は2〜5マスを重点化。
- 小学生〜一般向けに見慣れた名詞を中心とし、日常の使い方が明瞭な語を優先。
- 先頭の「ン」「ー」を除外。小書きカナは大書きに正規化。濁音・半濁音と長音符は残す。
- 語の表示と通常の読みを原形で残す。語長は `normalized` のUnicodeコードポイント数。
- 同じ正規化読みは語彙内で一つだけ。同音異義語は最初の300語では片方のみ採用し、候補・カギを再評価してから必要に応じて分ける。
- 固有名詞、作為的略語、意味の薄い断片、専門語、助詞・活用語尾込み表現は初期採用しない。
- カギは独自執筆。答えの文字列を直接載せず、特徴・用途・身近な場面などを適宜組み合わせる。
- 文字数やカテゴリの偏りは機械で把握し、不自然な語や別解の有無は編集レビューで判断する。

## 初期300語の位置付け
`seed_candidates.tsv` は選定の履歴用。状態はすべて `candidate`。
`approved_lexicon.tsv` は初期の編集チェックと構造検査を経た300語の**試作用採用データ**。状態 `editor_checked` は本セッションでの選定とカギ校正を示す。**第三者・利用者によるヒント解答テスト済みという意味ではない。** 人間の最終チェックが済んだ語は今後 `human_checked` に変更する。教材・自動公開問題では別途人による内容レビューを要求する。

## カテゴリ・難易度
初期は15カテゴリ各20語。「鳥と水の生き物」は鳥類・魚類・水辺の動物を含む。
難易度1: 生活の中で日常的に出会う語。2: 説明や知識をやや必要とする語。3: 将来の難語用（初期300語では未使用）。
分類は語の難しさの目安であり、カギの文量から機械的に決めない。

## 出典・ライセンス
初期300語の選定・ヒントは独自執筆で、外部辞書の見出し一覧・語義・頻度表を抽出・複製していない。`source=original_editorial_curation_2026-10-17` は**編集判断による選定**を意味し、外部辞書・コーパスの個別照合を実施した証明ではない。

将来、JMdictを確認・利用する場合は https://www.edrdg.org/edrdg/licence.html の利用条件を先に確認する。JMdict関連ファイルはEDRDGのCC BY-SA 4.0に従い、特に辞書ファイル・その派生データを取り込む際は出典表示、ライセンスと資料へのリンク、改変・継承条件をレビューする。外部辞書を参考に個々の語の一般的な用法を確認することと、辞書データを複製・配布することを区別する。国立国語研究所のコーパスも利用前に個別規約と提供形態を確認する。**今回の配布TSVはJMdictの派生データとして作成していない。**
