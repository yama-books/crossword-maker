# クロスワード語彙・ブラインド解答テスト手順（第1回）

対象：APP-002、編集中の2,000語義辞書。作成：2026-10-18 JST。

## 目的と試験範囲
**交差文字を見ない段階でどのような候補を思い浮かべるか**を小規模に調べる。今回は同じ意味の別の語が浮かびやすい組み合わせを意図的に集めた**24問の予備試験**であり、2,000語義全体から無作為抽出した代表サンプルではない。

## 配布するもの
- **回答者には** `data/lexicon/review/round8_blind_questions.tsv` のみ配布する。列は問題ID／盤面のマス数／ヒント／回答欄／自信度。マス数は小書きの「ゃ・ゅ・ょ・っ」も各1マスとして数える。回答はカタカナで記入。
- **採点者だけ** `data/lexicon/review/round8_blind_answer_key.tsv` を参照する。二つのTSVは同じQ番号で照合でき、GitHub上では両方見えてしまうため回答者は事前に解答ファイルを開かない。
- 自信度は「確信・たぶん・推測・わからない」など、回答者が選びやすい4段階で記録する。

## 解答テスト後の確認
1. 回答者には事前に解答を見せず、24問を解いてもらう。
2. 解答と想定文字列を比較し、一致・同じく成立する別解・不正解・無回答に分類する。
3. 別解は**ただちに不正解と決めつけず**、語の意味とマス数を確認する。実際のクロスワードでは交差文字を使って特定できれば許容する。正答率の低さだけでカギを一律改訂しない。
4. 可能なら難度や学齢の異なる複数人に試してもらい、回答者数・集計方法を明示する。
5. **実施前はすべて `editor_checked`。** 実際の第三者解答と校正判断の根拠を保存できた項目だけ、人手検証済みとして扱う。

## 今回の限界
- 24件に意図的な曖昧語を集めているため、正答率を全語彙へ外挿してはならない。
- 回答フォームや採点データをWebに公開しない。個人情報や生徒の成績は公開リポジトリへ書き込まない。
- 機械テストは問題と解答表が辞書の最新版と一致すること、および100ジャンルから5語ずつの既存M3a用形式出力を検証するだけ。**人が実際に解いたことや交差盤面の成立を保証しない。**

## 完成盤面を使う次の確認
- 完成した問題で、交差するヨコ・タテのカギを両方提示し、回答者が自然に答えを絞れるかを確かめる。
- 一部の文字を示してから再回答してもらい、交差によって解決した迷いと、なお残る矛盾・複数解とを分ける。
- **交差文字で一意に絞れるヒントは、単独で複数の解答が思い付くことを理由に修正しない。** まだ完成した盤面による回答試験は実施していない。
