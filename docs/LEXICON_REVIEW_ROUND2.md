# APP-002 語彙・カギ校正 第2回（2026-10-17）

## 校正の方法と範囲
初期300語を対象に、カギの差別化と読みの衝突リスクを横断的に確認した。第2回で追加した260語についてもヒントを独自に編集し、読みによる機械的な重複を禁止した。このレビューは編集上の抽出であり、第三者のブラインド解答テストを代替しない。今後のユーザーテストで最終判断する。

## 第2回で見つけた衝突と措置
- `漁師（りょうし）` と `理容師（りようし）` はカナ大書き化で双方 `リヨウシ` になる。前者を追加しないで `車掌` を採用。
- `待つ（まつ）` と既存 `松（まつ）` は `マツ` になる。前者を追加しないで `運ぶ` を採用。
- `水星` と `彗星` はともに `スイセイ`。今回は太陽に近い惑星の意味だけを登録し、彗星は登録していない。
- `琴` と `こと`（一般名詞）は語義が異なるためカギと表示語を固定。今回は楽器のみ。
- 動詞 `飛ぶ` は `跳ぶ` と同じ読みになりやすく、空中移動の意味に限定している。
