# APP-002 第4回：1,300語到達と別解リスクの改善
更新：2026-10-18 / 担当：語彙・カギ専用セッション

## 実施内容
- 15カテゴリ×20語、300件を追加。累計1,300語・65カテゴリ。
- 2〜5マス1186件、6マス以上114件。長語だけを増やさず短いマスも補充。
- 二つの読み衝突を選定中に発見。「表紙」と「拍子」（ヒヨウシ）、「かし」と「歌詞」（カシ）。
- 表紙は初期語彙を維持して、音楽カテゴリに「強弱」を追加。「かし」は樹木の「榊」に置き換え、音楽の「歌詞」を採用。変更は候補・採用の両TSVで同期した。
- 最初の候補で手がかり内に答えを含んでいた「大豆」「へそ」は修正した。
- `review_status=editor_checked` は編集レビューのみを示す。外部の人間による解答試験済みという意味ではない。

## 同じ盤面で混同しやすい組み合わせ
以下は語の読みが異なるため採用可能だが、ヒントの区別を実際の盤面で検証する。
| 組み合わせ | 懸念・推奨 |
| --- | --- |
| 森／林、池／湖 | 地形の大小や広がりだけでは境界が曖昧。マス数と周辺の説明を確認 |
| 旅／旅行 | 2マスと4マスの違いを生かし、手がかりの文脈を具体化 |
| お札／紙幣、値段／価格 | どちらも3〜4マスでカギが似やすい。意味の説明だけに依存しない |
| 洗い物／皿洗い | 日常の場面が重なる。対象と手順を明示する |
| 料理の動き：煮る／ゆでる／蒸す／焼く／揚げる | 水・蒸気・熱源・油の違いが伝わるようにする |
| 車輪／タイヤ、ブレーキ／アクセル | 部品とその働きを取り違えない具体的なカギを使う |
| 音／声、合唱／コーラス | 上位概念と具体例の混同を避ける |
| フード／帽子、バッグ／かばん | 用途が似る語。取り付け位置・語種を具体化 |

## 次の品質ゲート
対象学年と盤面マス数を指定して、**ヒントのみで回答してもらうブラインドテスト**を実施する。誤答例・修正前後・回答者人数を記録し、検証された語だけ `human_checked` に変更する。今回の段階では **human_checked 0語**。
`src/editor/`、`src/generator/`、UI・演出関係ファイルの編集は本作業に含めない。


## 2026-10-18 追記：同音異義語の扱いを変更
