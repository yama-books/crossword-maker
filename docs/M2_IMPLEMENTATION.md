# M2 制作画面・第1段階 実装記録

更新：2026-10-17  
ブランチ：work/m2-editor-20261017  
開発正本：https://github.com/yama-books/crossword-maker

## 目的

既存の「とく」画面と6×6・14問のプレイ動作をそのまま維持して、別ページ「つくる」の編集キャンバスを導入する。旧「クロスワード工房 v0.1」の自動生成・辞書補完は参考実装であり、今回は移植せず段階導入する。

## 今回の実装範囲

- editor.html：既存プレイ画面に似た明るい緑系の制作UI。ボタンはマットな8bit風のブロック型立体ボタン。実際のボタンを押下中に3px沈める。
- src/editor/model.mjs：未完成盤面でも保存可能なバージョン2のドラフト形式、単語枠・番号の再解析、作業途中の構造警告、完成時の厳格な validatePuzzle() 呼出し。
- src/editor/app.mjs：黒マス・文字・カギの編集、盤面サイズ5〜15、Undo/Redo（最大60操作）、端末内の自動保存、JSON書出・再読込、既存の完成問題JSON読込。
- 盤面登場時のみ6種類のランダムな出現演出（大盤面は3種類）。通常の文字入力時には再生しない。
- 「完成問題JSON」は空マス・未入力カギ・構造違反がない場合だけ有効。「作業JSON」は未完成でも随時保存。
- GitHub Pagesビルドでは editor.html、puzzle.json、実際に参照するソースモジュールを配布物 dist にコピーする。
- 既存 index.html は src/index.template.html から再生成し、「クロスワードをつくる」への導線のみ追加。プレイヤーのロジックは維持。

## M1とのデータ互換性

- 編集途中のJSON：kind = crossword-draft、schemaVersion = 2、grid（■/□/カナ）、clues、rules、title。
- 完成JSON：M1の puzzle.json と互換の grid、entries、numbers、title、ruleSet、rows、cols。正方形では size も出力。
- カタカナ正規化は M1の normalizeKana() を共用。ひらがな・半角カナ・小書きカナの処理を二重実装しない。
- カギは方向と開始位置で関連付ける。盤面の変更で座標や語枠が変わっても既存カギを勝手に上書きしない。不要なカギの履歴は作業JSONに残る可能性がある。
- 完成問題JSONは「現在の公開プレイヤーに取り込む準備が整った問題データ」であり、この編集画面からサイトの現在の問題を無断更新しない。

## 検証と制限

- Node.js 22 の組込テスト。追加したエディターテストでインポート、空欄、文字正規化、完成JSON、Undo用モデル、構造違反を確認する。
- CI：PRの自動テスト、既存プレイヤーの生成同期、Pagesビルド。
- 現在の制作画面は静的サイト向け。GitHub Pages上で稼働し、サーバー・外部ライブラリ・アカウント登録は必要ない。
- 問題の語義やカギの意味の品質は自動保証しない。外部辞書やAI生成語はまだ採用しない。
- iPhoneやPCの実機でタップ・日本語IME・保存・ファイル読込・印刷・表示の全機能を確認したとは報告しない。
- 作業JSONと完成JSONのどちらもユーザーが保存するファイルで、GitHubリポジトリや第三者に自動送信しない。

## 次の推奨作業

4. 盤面先行型のCSP補完、固定語の保護、未配置語の説明。
5. バッジポップ・ナッジ・トースト等のUI演出を慎重に追加。
