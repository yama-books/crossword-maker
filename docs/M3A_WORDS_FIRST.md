# M3a 単語指定型・配置案生成 試作記録

更新日: 2026-10-17
正本: https://github.com/yama-books/crossword-maker

## 目的

既存M1/M2の検証器・編集画面・14問のプレイ画面を維持し、ユーザーの語から交差する配置案を作る最小機能を追加。旧クロスワード工房v0.1の体験を参考にするが、ソースの全面移植はしない。

## 入力・仕様

- 編集画面で「表示名 | よみ | カギ」または「よみ | カギ」を1行ずつ入力。読みはM1の共通カナ正規化を通す。
- 2〜15文字の読み、最大60語、5〜15マス四方（縦横異なるサイズも可）。カギ欠落・無効な読み・重複を検出。
- ヨコ・タテの交差文字を一致させ、同方向の重複や意図しない隣接を禁止して配置。
- シード付きの有界な試行を重ねて配置語数・交差数・盤面のコンパクトさを評価。
- 採用語・未配置語を個別に表示。生成前の編集盤面はUndoで復元できる。
- ユーザー以外の語を自動で捏造せず、標準辞書を使う盤面先行補完はまだ行わない。

## 成立判定について

**配置案は完成クロスワードを保証しない。** 未使用マスを黒マスにするため、黒マスの連続禁止・180度対称などの既定ルールを満たさない場合がある。この場合は編集中ドラフトとして扱い、完成問題JSONの出力はM1共通 validatePuzzle() の合格時に限定する。

## 保存形式

従来のドラフトv2に任意のgenerationメタデータ（入力語、採用語、未配置語、交差数、シード、試行回数、編集後フラグ）を追加。既存JSONの読み込みは維持する。編集後の採用語数は再集計せず「前回の配置案」と明示する。

## 品質と未完了

- 入力検証、再現性、実際の語枠との一致、未配置語、M1完成判定との整合性をNode.js自動テストで確認する。
- iPhone Safari / PCの実機でのタップ、日本語IME、JSONダウンロードと再読込、印刷の操作確認は未実施。
- 未実装: 辞書による盤面先行型、必須・固定語保護、部分再生成、複数候補の比較、語義校正、Word出力。

## 次の手順

1. 「例の単語 → 配置案をつくる → 編集 → Undo → 作業JSON保存 → 読込」をiPhone等で検証。
2. 盤面先行型の辞書補完と、固定語を維持した部分再生成。
3. 生成候補の比較、学習難易度、印刷・Word/PDFの改善。
