# APP-002 iPhone Safari 実機確認（初回）

更新：2026-10-18 JST

## 実機で開くURL
- 解く： https://yama-books.github.io/crossword-maker/
- 作る： https://yama-books.github.io/crossword-maker/editor.html

**現在の解く画面は固定6×6・14問**。編集画面のM3aは「単語から配置案を作る」試作であり、全ルールに適合した完成問題を必ず生成するわけではない。辞書2,000語義のブラウザ直接取込は未実装。

## 確認する6項目
1. iPhone Safariで解く画面を開き、横スクロール不要で6×6盤面・タテ/ヨコのカギが読める。
2. マスをタップしてカナを入力し、文字が見える。**日本語IMEで入力・確定**してもおかしな文字や予期しないカーソル移動がない。
3. 交差するマスを二度タップすると、タテ/ヨコが切り替わる。カギのボタンをタップすると対応マスがハイライトされる。
4. 「答え合わせ」「1文字ヒント」「すべて消す」を試す。途中入力が残るかはページを再読み込みして確認する。
5. 作る画面に移り「例の単語を入れる」→「✦ 配置案をつくる」。採用・未配置の表示と盤面描画、入力欄への文字入力を確認する。**配置案が完成検査に通らないこと自体は既知の制約**。
6. 「↓ 作業JSONを保存」で端末にダウンロードできるかを確認。可能なら「↑ JSONを読み込む」で戻せるか試す。スマホのダウンロード操作が難しければその事実を記録する。
